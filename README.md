# Godot 合成音效生成器（AudioStreamWAV）

在界面输入参数，逐采样合成 16-bit PCM 音效，封装为 `AudioStreamWAV` 播放，
并调用 `save_to_wav()` 导出为 WAV 文件。核心合成逻辑是 `scripts/main.gd`
里的 `_tone()`：相位累加（滑音不爆音）+ 五种波形 + 可选滑音曲线 + 指数衰减包络。

## 运行

- 用 Godot 4.x 打开本项目（`project.godot`），按 F5 运行；
- 或命令行：`godot --path .`

首次启动会用默认参数合成、播放，并导出一份 `sounds/blip.wav`，开箱即得成品文件。

## 界面参数

| 参数 | 含义 |
| --- | --- |
| 波形 | sine（柔和）/ square（刺，机械感）/ tri（圆润）/ saw（明亮锋利）/ noise（白噪声，与音高无关） |
| 起始频率 | 基频，Hz |
| 结束频率 | > 0 时随时间滑音到该频率（上扬/下坠音效）；≤ 0 表示不滑音 |
| 滑音曲线 | 线性 = 频率匀速变化；指数 = 频率等比变化，按人耳对音高的对数感知更均匀自然（需结束频率 > 0，否则该选项禁用） |
| 时长 | 音效长度，0.05~2 秒 |
| 衰减 decay | 指数衰减速率，越大消失越快 |
| 音量 | 峰值幅度 0~1（包络自带淡入/衰减，不会削波） |
| 文件名 | 快速导出到 `sounds/<文件名>.wav`，非法字符自动过滤 |

## 按钮

- 「合成并播放（空格）」：按当前参数合成、播放并刷新波形预览（不写文件）；
- 「仅播放」：重播当前音效；
- 「导出 WAV」：把当前音效写入 `sounds/<文件名>.wav`；
- 「另存为…」：弹出文件对话框，保存到任意位置（覆盖已有文件会先确认）。

## 其它功能

- **波形预览**：面板中部以 DAW 风格（逐像素 min/max 振幅包络）显示当前音效，改参数立刻能看到形状变化；
- **参数记忆**：上次使用的参数自动保存在 `user://settings.cfg`，下次启动恢复；
- **预设**：经典 Blip / 上扬 Launch / 下坠 Drain（指数滑音）/ 敲击 Hit / 金币 Coin / 爆炸 Boom，一键填参并生成。

## 技术要点

- 相位累加器代替 `sin(t * f)`：变频率（滑音）时相位始终连续，不会产生"咔"的爆音；
- 滑音曲线：线性 `lerp(f0, f1, k)`；指数 `f0 * (f1/f0)^k`（对数域等比）；
- 约 2 ms 快速淡入 + 指数衰减包络：起止都安静、无咔哒声，且乘积达不到 1.0，天然无削波；
- 22050 Hz 采样率对短音效足够，数据量比 44100 Hz 少一半；
- 编辑器内快速导出到 `res://sounds/`；导出的游戏内自动改写到 `user://sounds/`；「另存为…」不受此限制；
- 想把导出的 WAV 当普通资源用：`var s: AudioStreamWAV = load("res://sounds/xxx.wav")`。
